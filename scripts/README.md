# بناء صفحات S4T32

من جذر المستودع شغّل `python3 scripts/build_site.py` ثم `python3 scripts/test_site.py` و`node --check assets/site.js`. لا يحتاج البناء اتصال شبكة أو مكتبات Python خارجية. مصدر شروط القسائم هو `data/coupons.json`، والمحتوى الثابت وتعليمات الاستخدام في `build_site.py`. HTML الناتج يعمل دون JavaScript؛ JavaScript يضيف النسخ والبحث فقط.

البناء يحدّث سبع صفحات موجودة، ويحافظ على عناوين sitemap التسعة. العربية والإنجليزية تستخدمان مصدر بيانات القسائم نفسه. لا يضيف ملفات الفيديو أو بيانات الحساب، ولا ينقل الاستضافة أو النطاق، ولا يدّعي صلاحية عالمية أو خصمًا ثابتًا. تاريخ مراجعة الفيديو لا يساوي تاريخ تجربة الكود. لا تغيّر حالة التحقق أو الصلاحية قبل دليل جديد.

لقطة الساعة العامة الخفيفة محفوظة في `assets/evidence/clock-2026-11-15.webp`. سجل `dateEvidence` يميز تاريخ التجربة الذي أبلغ به صاحب الموقع مع اللقطة عن تاريخ تصوير موثق مستقلًا؛ لا تتغير حقول تحقق السلة والشراء بوجود صورة ساعة. الصورة كاملة، بلا بيانات EXIF، وتحمل أبعادًا صريحة وتُحمّل عند الحاجة في قسم الإثبات. أبقِ قيمة `data-copy` مطابقة للرمز الأصلي مهما تغيّرت الصياغة.

حُذفت نسختا اسم ملف التحقق ذواتا المسافة و`(8)` فقط؛ الملفات الأصلية الثلاثة محفوظة. لا تغيّر `BASE` أو `PATH` ولا Canonical أو sitemap إلى نطاق جديد قبل شراء النطاق المؤكد وتجهيز الاستضافة والتحويلات والتحقق. تغيير النطاق وحده لا يغيّر شروط الاستخدام التجاري لـGitHub Pages.
