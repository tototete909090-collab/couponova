# بناء صفحات S4T32

من جذر المستودع شغّل `python3 scripts/build_site.py` ثم `python3 scripts/test_site.py` و`node --check assets/site.js`. لا يحتاج البناء اتصال شبكة أو مكتبات Python خارجية. مصدر شروط القسائم هو `data/coupons.json`، والمحتوى الثابت وتعليمات الاستخدام في `build_site.py`. HTML الناتج يعمل دون JavaScript؛ JavaScript يضيف النسخ والبحث فقط.

البناء يحدّث سبع صفحات موجودة، ويحافظ على عناوين sitemap التسعة. العربية والإنجليزية تستخدمان مصدر بيانات القسائم نفسه. لا يضيف ملفات الفيديو أو بيانات الحساب، ولا ينقل الاستضافة أو النطاق، ولا يدّعي صلاحية عالمية أو خصمًا ثابتًا. تاريخ مراجعة الفيديو لا يساوي تاريخ تجربة الكود. لا تغيّر حالة التحقق أو الصلاحية قبل دليل جديد.
